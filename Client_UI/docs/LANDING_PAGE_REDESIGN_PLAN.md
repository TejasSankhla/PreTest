## Messaging Strategy

### Target Audience Profile

| Segment | % | Description |
|---------|---|-------------|
| College Students | 90% | Preparing for placements, internships, upskilling |
| Fresh Graduates | 10% | <1 year experience, job hunting or switching |

### Core Pain Points (Ranked)

1. **Fear & Anxiety** - "Will I fail the interview? I don't know what to expect"
2. **Confusion** - "How do I even prepare? Where do I start?"
3. **Isolation** - "No seniors or mentors to guide me through this"
4. **Frustration** - "Platforms like Pramp are expensive or not India-focused"

### PreTest's Unique Value Proposition

| Differentiator | What It Means | Why It Matters |
|----------------|---------------|----------------|
| Community-Powered | Mentors are peers who recently cracked interviews | Relatable, recent experience, same context |
| Affordable | Community-maintained pricing | Accessible to tier-2/3 college students |
| Indian Context | Mentors understand Indian placements, FAANG hiring in India | Relevant advice, not US-centric |
| Not Transactional | More like talking to a supportive senior | Comfortable, less intimidating |

### Brand Voice: Supportive Reality Check

**Tone Characteristics:**
- Empathetic but honest ("We've all been there")
- No fluff, straight to the point
- Challenges assumptions without being harsh
- Confident but not arrogant
- Like a senior who cares enough to tell you the truth

**Do's:**
- "We've all been there" ✓
- "Here's what actually works" ✓
- "The gap between knowing and doing" ✓
- "Make your mistakes here, not there" ✓

**Don'ts:**
- "You're amazing!" ✗ (too emotional)
- "You're doing it all wrong!" ✗ (too aggressive)
- "Transform your career journey!" ✗ (fluff)
- "Best platform ever!" ✗ (sales-y)

## Psychological Messaging Framework

### Primary Angle: The Experience Gap

**Core Truth:**
Knowledge ≠ Performance under pressure. You can study for months and still freeze when someone's watching.

**Why it works:**
- Every student who's prepared alone has felt this anxiety
- It validates their fear while offering a solution
- It positions practice as the missing piece, not more study

**Key phrases:**
- "The gap between knowing and doing"
- "You've learned it. Now practice it."
- "Courses teach what to say. Practice teaches how to say it."

### Secondary Angle: Fail Here, Not There

**Core Truth:**
Every real interview you fail is an opportunity lost forever. Mock interviews let you make mistakes safely.

**Why it works:**
- Creates urgency without being pushy
- Positions PreTest as a safe space
- Appeals to loss aversion (don't lose real opportunities)

**Key phrases:**
- "Fail here. Not there."
- "Your first interview shouldn't be your real interview"
- "Make your mistakes before they matter"

### Why This Tagline Works

| Element | Purpose |
|---------|---------|
| **"Preparation ≠ Practice"** | Creates curiosity, challenges assumption, research-backed (Testing Effect) |
| **"That's the gap we close."** | Positions PreTest as the solution, confident, short |
| **Mathematical symbol (≠)** | Visually striking, memorable, implies a truth/equation |
| **Two-line structure** | Easy to scan, punchy, works on mobile |

### Alternative Headlines (for A/B Testing)

| Option | Headline | Subheadline | Angle |
|--------|----------|-------------|-------|
| A (Primary) | Preparation ≠ Practice. | That's the gap we close. | Testing Effect |
| B | Prepared ≠ Practiced. | That's the gap we close. | Testing Effect (past tense) |
| C | Knowing ≠ Showing. | Practice until you can show what you know. | Testing Effect (rhymes) |
| D | What if studying isn't the problem? | Mock interviews reveal what's really missing. | Curiosity |
| E | The best students aren't always the best interviewees. | Because interviews test performance, not just knowledge. | Counter-intuitive |

### Headline Pairing Strategy

**Hero (Top of page):** Testing Effect / Curiosity angle
```
Preparation ≠ Practice.
That's the gap we close.
```

**CTA Banner (Bottom of page):** Safe Failure angle
```
Don't Let Your First Real Interview Be Practice
```

**Psychological Journey:**
1. **Top (Hero):** "Hmm, they're right—I've prepared but never actually practiced under pressure"
2. **Middle:** Shows how PreTest works, introduces mentors, builds trust
3. **Bottom (CTA):** "I shouldn't risk my real interview"—triggers action with loss aversion

## Variant Switching System

### Implementation

```tsx
// app/page.tsx
const [variant, setVariant] = useState<LandingVariant>("v1");

// Load from localStorage
useEffect(() => {
  const saved = localStorage.getItem("landing-variant");
  if (saved === "v1" || saved === "v2") setVariant(saved);
}, []);

// Persist choice
const handleVariantChange = (newVariant: LandingVariant) => {
  setVariant(newVariant);
  localStorage.setItem("landing-variant", newVariant);
};

// Conditional rendering
if (variant === "v2") {
  return <V2Components />;
}
return <V1Components />;
```

### Variant Switcher Component

- Fixed position: `bottom-6 right-6`
- Glassmorphism background
- Dropdown with radio-style selection
- Shows current variant name
- Persists in localStorage
